# 数据分析执行

执行数据分析任务。

## 允许的操作
- 使用 MCP 工具查询数据库（SQL、NoSQL、API）
- 运行 Python/R 脚本进行数据处理和建模
- 使用 shell/command 执行 pip install、数据下载等准备操作
- 将分析结果写入文件（JSON、CSV、图表）

## 工作流程
1. 获取数据：通过 MCP 工具或 API 查询
2. 清洗处理：运行数据处理脚本
3. 分析建模：统计计算、机器学习
4. 结果输出：导出图表、报告数据

## 注意事项
- 大数据量查询使用分页或采样
- 中间结果保存到 workspace 文件
- 长时间运行需要提供进度反馈

## 危险命令禁止
- 禁止删除原始数据
- 禁止修改生产数据库
